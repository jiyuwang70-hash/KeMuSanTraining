# Antigravity 中文交互规则 (Language Rules)

- **语言首选**：始终默认使用**简体中文**与用户进行所有交流、解答、规划和回复。
- **思考与任务**：思考过程（Thinking）、任务拆解（Task List）、执行步骤和总结汇报必须使用中文呈现。
- **代码与注释**：为代码编写的说明文档、函数注释、错误提示及用户指引均优先采用中文。
- **界面交互**：所有生成的脚本提示、控制台输出、UI 卡片及按键向导必须为全中文友好设计。
