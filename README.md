# 科目三路考模拟（KeMuSan Road Test Simulator）

考驾照**科目三（道路驾驶技能考试）**模拟训练游戏，基于 **Unreal Engine 5.7** 开发。

把真实考场搬进电脑：完整的上车准备、夜间灯光模拟、起步、直线行驶、变更车道、通过路口/人行横道、学校区域、公交车站、会车、超车、加减挡、掉头、靠边停车 14 个考试项目，全部按照科目三考试规则实时判定扣分，100 分制、90 分合格。

## 快速开始

1. 安装 **Unreal Engine 5.7**（Epic Games Launcher）与 **Visual Studio 2022**（勾选「使用 C++ 的游戏开发」）。
2. 双击 `KeMuSanTraining.uproject`，选择引擎版本 5.7 打开。
3. 首次打开会自动编译 C++ 代码，完成后点 **Play（▶）** 运行。
4. 主菜单按 **Enter** 开始考试，**F9** 自由练习。

也可以命令行编译：

```
D:\UE_5.7\Engine\Build\BatchFiles\Build.bat KeMuSanTrainingEditor Win64 Development -Project="<项目路径>\KeMuSanTraining.uproject" -WaitMutex
```

## 操作键位

| 按键 | 功能 | 按键 | 功能 |
| --- | --- | --- | --- |
| `W` / `S` | 油门 / 刹车 | `A` / `D` | 转向 |
| `1`–`5` | 挂 1–5 挡 | `N` / `R` | 空挡 / 倒挡 |
| `Q` / `E` | 左 / 右转向灯 | `J` | 远近光交替（闪灯） |
| `L` | 灯光循环（关→示廓→近光→远光→关） | `K` | 雾灯 |
| `H` | 危险报警闪光灯（双闪） | `Space` | 手刹 |
| `F` | 安全带 | `B` | 喇叭 |
| `M` | 观察后视镜 / 回头（考试必按！） | `Enter` | 开始 / 重考 |
| `Esc` | 暂停 | `F9` | 自由练习模式 |

> 灯光模拟考试阶段，数字键 `1`–`5` 用于答题：
> `1` 近光 · `2` 远光 · `3` 远近交替 · `4` 示廓灯+双闪 · `5` 雾灯+双闪

## 考试项目与评分规则（100 分制，90 分合格）

| # | 项目 | 判定规则（简） |
| --- | --- | --- |
| 1 | 上车准备 | 系安全带（F）、观察（M）、拉手刹（空格） |
| 2 | 夜间灯光模拟 | 8 道随机题，答错/超时 **不合格**（真实规则） |
| 3 | 起步 | 左转向灯、观察、松手刹、挂 1 挡；后溜 >30cm 不合格；猛给油/高挡起步会**熄火**（-10） |
| 4 | 直线行驶 | 方向偏差 >3° 或横向偏移 >0.45m 持续 1 秒 → 不合格 |
| 5 | 变更车道 | 先左后右两次变道，未打灯/不足 3 秒/未观察各 -10 |
| 6 | 通过路口 | 闯红灯不合格，黄灯抢行 -10，超 35km/h -10 |
| 7 | 人行横道 | 遇行人不停车让行不合格，超 30km/h -10 |
| 8 | 学校区域 | 超 30km/h 不合格 |
| 9 | 公交车站 | 超 30km/h 不合格 |
| 10 | 会车 | 靠右行驶（压中心线不合格） |
| 11 | 超车 | 左侧超车；未打灯/未观察/未返回原车道各 -10，右侧超车不合格 |
| 12 | 加减挡 | 加至 4 挡再减至 2 挡；越级换挡 -10，未完成 -10 |
| 13 | 掉头 | 左转向灯、观察、减速；未完成/未打灯/未观察各 -10，反向掉头不合格 |
| 14 | 靠边停车 | 距路缘石 ≤30cm 满分，30–50cm -10，>50cm 或压路缘石不合格；停车后挂空挡+拉手刹 |

通用判罚：超 60km/h、骑轧车道中心分界线、未系安全带、驶出路面 → 不合格；熄火、手刹行驶 → -10。

## 项目结构

```
KeMuSanTraining/
├── KeMuSanTraining.uproject      # UE 5.7 工程文件
├── Config/                       # 按键映射、默认地图、GameMode 配置
├── Source/KeMuSanTraining/
│   ├── KeMuSanGameMode           # 游戏模式（考试/练习模式开关）
│   ├── KeMuSanPawn               # 考试车：手动挡运动学 + 灯光/信号/手刹/安全带
│   ├── KeMuSanPlayerController   # 挡位键、灯光考试答题、开始/暂停/重考
│   ├── KeMuSanHUD                # 全中文 Canvas HUD（提示、分数、进度、结果面板）
│   ├── ExamController            # 考试核心：阶段机 + 14 个项目判定 + 评分
│   ├── RoadBuilder               # 运行时程序化生成整条考试路线与场景
│   ├── TrafficActors             # AI 会车/慢车、过街行人、红绿灯
│   ├── BeepSynth                 # 程序化合成提示音（叮/警示/喇叭/转向/引擎）
│   ├── ExamTypes.h               # 阶段/挡位/题目/扣分等公共类型
│   └── RoadLayout.h              # 考试路线几何常量（米）
└── Content/                      # 模板地图与网格资产（二进制，来自 UE 车辆模板）
```

## 设计说明

- **路线**：约 520 米长的双向两车道考试路段 + 路口 + 掉头区，全部由 `ARoadBuilder` 在运行时用基础几何体程序化搭建（坐标见 `RoadLayout.h`），不依赖手摆关卡。
- **车辆物理**：简化自行车模型（速度关联转向角、挡位限速、油门开度控制、刹车/手刹/阻力、熄火模拟），键盘即可流畅驾驶。
- **灯光**：近光/远光/示廓/雾灯/双闪/左右转向灯均有独立状态与视觉反馈，转向灯回正自动取消。
- **音频**：`USoundWaveProcedural` 实时合成 16bit PCM——提示叮声、双叮、警示音、喇叭、转向滴答、随转速变化的引擎声，无需任何音频资产。
- **判罚**：`AExamController` 每帧监控超速、压线、安全带、手刹、熄火等全局违规，按区域触发 14 个考试项目并记录扣分明细，考试结束给出合格/不合格与完整扣分清单。

## 已知限制与后续方向

- 考试车为程序化拼装外观（立方体车身），可自行替换为车辆模型。
- 语音播报为合成提示音 + 屏幕文字，如需真人语音可接入 TTS。
- 未做碰撞体：锥桶/路缘石仅作视觉与判分参考，碰撞检测可后续接入 Chaos 物理。
- 模板地图（VehicleBasic）引用了少量引擎演示资产（如 `/Game/Vehicles/PhysicsMaterials`），首次打开时日志中会出现无害的加载警告，不影响游戏。
